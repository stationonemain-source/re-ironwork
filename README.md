# RE Ironwork — door configurator prototype

A design prototype for a custom forged-iron door shop. The configurator shows a rendered
photograph for every combination of configuration, style, finish and glass (120 doors).

- Door renders are AI-generated concept photography.
- Branding, copy, projects, prices, lead times and contact details are placeholders.
- The quote form does not send anything.

Static site: open `index.html`, or view it on GitHub Pages.
